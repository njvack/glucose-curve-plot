# glucose-curve-plot

A plotter for glucose curve data stored in Google Sheets

Mostly vibe-coded with Claude Code.

### How to use this

* Copy the [Glucose Curve Template](https://docs.google.com/spreadsheets/d/1wacUPAUHC9cMvO4a_ZEffU7LH7TVgHoX-TEAQ1GGfeA)
* Set permissions to "Anyone with the link can view"
* Enter data for your glucose curve(s)
* Copy the link for the sheet
* Visit [the plotting page](https://njvack.github.io/glucose-curve-plot/)
* Paste in the link

You can copy the URL for that page and send it to your vet (or anyone you want to, really)
